# 159567：3万元、5分钟检查、每日20轮的假设价格路径压力测试

## 结论

本报告的结论为 **No-Go**：现有30日5分钟数据不能计算真实成交胜率或真实盈利率，也不支持“每天机械完成20个往返可以盈利”的判断。

本次3万元、每日最多20个往返来自用户指定的独立压力情景。它不替代PRD冻结的“1万元、50%基础仓位/50%现金、带完整风险控制”研究基线，也不能作为策略准入依据。

在明确忽略买卖价差和滑点、只收取每次买入5元与卖出5元的最低佣金时：

- 机械假设20条往返价格路径/日，其中净收益为正的路径占35.67%，净收益为正的日期占46.67%；
- 30日净亏损3,069.80元，相当于初始3万元的-10.23%；
- 30天共600轮，最低佣金累计6,000元；
- 零成本情景虽然盈利3,188.70元，但日均收益的95%近似区间为-91.24至303.82元，跨过0，不能证明存在稳定正收益；
- 若每个完整往返额外损失一个0.001元的价格跳动，机械基线净亏损20,989.00元。

“每天20轮”应当是绝对上限，不应成为必须完成的交易指标。

## 回测性质与证据状态

本报告为 **MVP派生计算**，没有专用盘口成交模拟器。所有“买入价、卖出价、数量和盈亏”都是OHLC价格路径假设，不代表用户订单能够按该价格和数量成交。证据状态是：

`insufficient_evidence_for_profitability_or_live_use`

| 项目 | 证据与质量状态 |
| --- | --- |
| 行情输入 | 本机DVC版本化的159567原生5分钟数据 |
| 数据窗口 | 2026-06-12至2026-07-24，最近30个完整交易日 |
| 数据规模 | 1,440根5分钟bar，每日48根 |
| 结构质量 | 无缺bar、重复时间戳、零/负价格或OHLC逻辑错误 |
| 成交证据 | 无历史买卖盘口、挂单量、逐笔成交或历史IOPV |
| 费用证据 | 用户报告每边最低5元；佣金比例、部分成交和经手费包含关系仍未书面校准 |
| 回测实现 | `src/etf_t0/coarse_backtest.py`中的假设价格路径MVP派生计算 |

本报告不能给出真实“交易胜率”。表中的“假设路径为正比例”是净收益为正的OHLC假设路径数除以全部假设路径数；“正收益日期占比”是当天假设盈亏为正的天数比例；“Profit Factor”是假设盈利路径之和除以假设亏损路径绝对值；“日终最大回撤”是从初始3万元及其后的日终假设权益峰值到后续日终低点的最大跌幅，不包含日内路径；`bp`是基点，100bp等于1%。

## 固定假设

为回答“3万元、5分钟数据、每天20次”的问题，本报告将“20次”解释为每天20个完整的买入—卖出往返，而不是20笔单边委托。

### 机械20轮基线

- 每个交易日从48根5分钟bar中确定性地、均匀选取20根；
- 假设可在选中bar的开盘打印价进入、同一bar的收盘打印价退出；
- 开盘先于收盘，因此没有使用bar内高低点虚构价格顺序，但这仍不代表可成交；
- 每轮最多使用3万元，按100份整数单位取整；
- 账户亏损后可用资金同步下降，盈利后单轮投入仍封顶3万元；
- 每日固定完成20轮，共600轮。

这不是一项预测策略或成交回测，而是检验“无论是否出现机会，都要做满20条价格路径”的成本压力基线。

### 暂定费用下的保本价格变动

复用 `fees.break_even_for_round_trip` 对上述600条机械假设路径逐条计算。实际券商比例佣金、经手费包含关系、部分成交收费及交割单核对尚未取得，因此实际费用仍为 **G0 BLOCKED**。

| 暂定费用情景 | 路径入场打印价 | 数量范围 | 完整往返经济成本 | 最小价格变动 | 最小跳数 | 对应价格收益率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 每边最低5元，经手费假设已包含 | 0.572–0.728元 | 39,100–50,700份 | 10.00元 | 0.001元/份 | 1跳 | 0.137%–0.175% |
| 每边最低5元，经手费假设另收 | 0.572–0.728元 | 39,100–50,700份 | 12.15–12.40元 | 0.001元/份 | 1跳 | 0.137%–0.175% |

这里的“1跳保本”只表示在约3万元全部按打印价成交、且忽略买卖价差和滑点时，0.001元/份的毛价格变动足以覆盖上述暂定显性费用。它不是成交概率或目标收益。用户原先的“每次收益超过5元”口径不够：一个完整买入—卖出往返至少先覆盖10元显性佣金，再覆盖价差、滑点及其他经交割单确认的费用。

可用以下命令复现，结果位于 JSON 的 `provisional_break_even_cost_coverage`：

```bash
PYTHONPATH=src uv run python -m etf_t0.coarse_backtest \
  --input data/interim/159567_5m_latest/bars.csv \
  --capital 30000 \
  --round-trip-limit 20
```

### 无风控的探索性因果均值回归路径

- 锚点：当日12根5分钟收盘价的因果EMA；
- 入场条件：已完成bar的收盘价低于EMA 30个基点；
- 信号产生后，假设不早于下一根bar开盘打印价进入；
- 收盘价回到EMA后，假设于下一根bar开盘打印价退出；
- 仍未退出的路径假设按当日最后一根bar的开盘打印价结束，以避免看到最后收盘后再按同一收盘价退出；
- 单次只允许一个多头仓位，每日最多20轮，不持仓过夜；
- 此处故意不实现PRD策略基线要求的1%日损停止、80%投入上限、3%回撤暂停和5%版本失败规则，用于观察未设风控时的反证性结果；
- 这不是策略基线或推荐参数，不能推进G4至G8。

基础仓位的涨跌未计入主动网格收益，以免ETF本身上涨掩盖交易策略亏损。

## 是否需要1秒数据

人工下单不需要系统每秒生成一次交易决策；5分钟完全可以作为“检查策略”的频率。

但5分钟检查频率与成交数据粒度是两件事。即便每5分钟只做一次判断，在准备下单时仍需要一条尽可能新的买一、卖一和挂单量快照，否则回测无法知道：

- 看到的价格是可以买到的卖一，还是只能卖出的买一；
- 3万元是否能在该档位完全成交；
- 一轮实际损失了0跳、1跳还是更多；
- 限价单是否只是触价而没有成交。

因此，不必坚持“全天1秒采集才能人工交易”，但至少需要在每个5分钟决策点及实际委托前后保存实时盘口。若免费源足够稳定，持续1至3秒采集是为了研究和复盘成交质量，而不是为了自动下单。

## 限制与反证

1. 30日只有一个很短的市场阶段，不能证明长期胜率或盈利率。
2. bar开盘价和收盘价只是该5分钟区间的打印价格，不是用户可执行成交价；没有对应档位数量，3万元未必能全部成交。
3. 没有买卖盘口，压力情景不能替代真实价差和滑点。
4. 用户只确认了每边最低5元；若3万元对应的比例佣金高于5元，实际亏损会更大。
5. 没有处理部分成交、撤单、排队、IOPV陈旧、暂停申赎或跨市场错位日；特别是2026-07-01尚未正式标记，30日结果混入了非正常重合日。
6. 机械20轮没有价格预测能力，只回答强制高频交易的成本后果。
7. 因果EMA只是一个简单的无风控反证路径；其失败不证明所有人工网格都失败。
8. 本计算没有实现PRD策略基线的日损、投入上限和回撤暂停规则，因此不能当作可执行策略回测。
9. 本报告不提供具体买卖点、仓位比例或7月27日实盘指令。

## 下一步

在确定新策略参数前，应先：

1. 从下一交易日起，在每个5分钟决策点采集买一、卖一、对应挂单量和IOPV；
2. 记录用户实际人工委托与脱敏成交回单；
3. 用真实价差、滑点和佣金比例替换本报告的成本敏感性假设；
4. 将“每天最多20轮”保留为上限，让策略在没有成本后机会时选择0轮；
5. 积累至少20个交易日的模拟执行，再讨论受控人工验证。
