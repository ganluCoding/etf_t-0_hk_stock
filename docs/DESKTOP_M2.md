# 桌面观察应用 M2 使用与运维

## 当前能力与边界

M2 是连接本机当日研究数据的桌面软件，不是自动交易程序。当前唯一注册目标是 `159570`；内部参考只参与研究计算，不在主界面出现，也不是用户需要交易的第二条腿。

桌面程序可以：

- 在连续竞价时段读取 30 秒内的目标买一、卖一和 IOPV。
- 后台执行网络刷新，防止界面卡死；首次成功后每 15 秒刷新。
- 显示因果 5 分钟 bar 进度和 G2/G3 阻断原因。
- 使用版本化的 2026 正常重合日历；港股通关闭、半日服务、周末或日历有效期外均清价。
- 遇到非注册代码、非连续竞价、旧快照、时钟回拨、交叉价格、采集错误或成本空间不足时清空所有价格。
- 将每个界面决策原子保存到本机 `reports/generated/desktop_decisions/`；记录只含目标展示字段，不含券商凭据或内部参考代码。

当前公开网络源的页面条款不保证时效、连续或准确，所以它始终标记为 `UNVERIFIED RESEARCH FEED`，G2/G3 未通过且实盘准入始终为 `✕`。不足 48 根连续因果 5 分钟 bar 时进入 `WAIT-DATA`、观察线为空；累计足够数据后，也只有当前快照、资格、冻结策略 lineage 和保守成本门禁全部通过，才显示带水印的纸面观察价。纸面价不是可成交行情或下单建议。

## 启动

```bash
uv sync --all-groups
PYTHONPATH=src uv run python -m etf_t0.desktop_app
```

输入 `159570` 后点击“开始观察”。按钮显示“正在刷新…”时，网络任务在后台执行。如需验证 M1 界面而不读真实数据，必须显式使用：

```bash
PYTHONPATH=src uv run python -m etf_t0.desktop_app --demo
```

macOS 可双击版由同一个已测试环境生成：

```bash
PYTHONPATH=src uv run python -m etf_t0.macos_bundle
open "dist/T0 ETF Observation.app"
```

该 `.app` 是本机启动器，绑定当前工作区和 `.venv`；不是可复制到其他电脑的独立签名安装包。它通过 macOS LaunchServices 让 Terminal 打开应用包内的 `launch.command`，不使用 AppleScript、也不请求“控制 Terminal”权限。Terminal 必须具备读取当前 Documents 工作区的权限。启动日志位于 `reports/generated/desktop_app/`。

## 数据与计算契约

1. 采集器每 15 秒保存成对快照，每 5 分钟同步原生 1 分钟数据。
2. 只接受在报价时点之前已经收到、OHLC 合法、两标的同时点、连续 5 根的 1 分钟 vintage。
3. 完整 5 分钟 bar 使用最后一根 close，可用时间是两标的五根 vintage 中的最晚接收时间。
4. 只有报价晚于全部信号 bar 可用时间，才能作为“下一可用 quote”。
5. 历史完整交易日包含 15:00 bar；桌面 14:57 后清价并不删除已经完成的历史 15:00 信号 bar。跨日 L48 按版本化正常重合日历跳过关闭日。
6. 冻结策略使用 `log(target_close/reference_close)`、L48、`ddof=0`、入场 `-1.5σ`、退出 `-0.25σ`；买价向下取到 0.001，卖价向上取到 0.001。完整 `forward_collection.json` canonical SHA-256 固定，保留同一 ID 的参数漂移也会直接 No-Go。
7. 当前 159570 尚未完成券商账单校准。M2 使用通用临时压力情景：每个已成交买入和卖出分别按最低 5 元，并保留经手费另收的保守情况；这不是把 159567 的用户报告费率认定为 159570 的实际费率。
8. 研究基线总资金为 10,000 元，其中当前纸面入场只使用 5,000 元现金侧；数量按 100 份整数倍并在买入前预留买侧费用。
9. 盈亏平衡价逐 0.001 价格档重算卖侧费用，直到覆盖买卖双边费用及 2 个价格档的执行缓冲。

合成回归测试可以验证价格计算，但不能改变真实数据的 G2/G3 状态。

## 连续采集与恢复

项目使用两个 Codex 本地定时任务：工作日 09:25 和 12:55 各启动一次 135 分钟有界采集。采集器有单实例锁，重复任务不会重复写入。采状态位于：

```text
reports/generated/forward_capture/collector_heartbeat.json
reports/generated/forward_capture/latest_manifest.json
```

当点击后无数据时，按以下顺序检查：

1. 当前是否为 09:30–11:30 或 13:00–14:57连续竞价。
2. 心跳是否在 45 秒内且 PID 存活；`FAILED` 时查看 `error`，`INTERRUPTED` 时查看 `reason`。
3. `latest_manifest.json` 是否在 30 秒内，且包含 159570 的当日买一、卖一与 IOPV。
4. 界面是否显示可操作的网络/采集错误。修复后点“重试刷新”。

休眠、断网或行情超过 30 秒时，界面会清空诊断盘口与策略价格。应用恢复到前台后会立即重新刷新；网络错误也可点击“刷新观察”重试。
