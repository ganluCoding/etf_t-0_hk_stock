# Triage Labels

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估。 |
| `needs-info` | `needs-info` | 等待补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 agent 执行。 |
| `ready-for-human` | `ready-for-human` | 需要用户决策或人工实施。 |
| `wontfix` | `wontfix` | 不再处理。 |

附加分类标签：

- `type:research`：假设、回测、验证。
- `type:data`：数据采集、质量、口径、谱系。
- `type:strategy`：信号、执行、风险模型。
- `type:infra`：仓库、环境、自动化、CI。
- `risk`：金融、数据或操作风险。
- `blocked`：依赖外部数据、费用信息或用户决策。
