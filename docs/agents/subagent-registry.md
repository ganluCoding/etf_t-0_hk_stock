# Sub-agent 注册表

本表登记本项目可复用的专业 sub-agent 角色、最小输入与输出边界。它是版本化的角色注册表，不保存账户凭据、行情数据或交易权限。

运行时 agent 由当前任务按需唤起；本文件保证在未来任务或新会话中可按同一职责和提示词重新创建，而不假定某个运行时进程永久存在。

| 注册名 | 角色与触发条件 | 必读输入 | 输出与限制 |
| --- | --- | --- | --- |
| `market_rules_review` | 标的资格、交易所规则、交易时段、费用或跨市场机制发生变化时 | `PRD.md`、`CONTEXT.md`、标的台账、交易所一手资料 | 给出事实依据、适用范围和待确认项；不下单、不把第三方转载当作资格证据。 |
| `quant_method_review` | 新建或修改锚点、网格、回测、成交、库存或风险控制时 | `PRD.md`、`CONTEXT.md`、相关代码与测试 | 审查因果性、成本、库存、100 份约束、无同 bar 虚构成交；不宣称 30 日样本证明盈利。 |
| `prd_consistency_audit` | 每个合并前 PR、阶段门结论，以及每 5 条用户对话时 | `PRD.md`、`CONTEXT.md`、相关 Issue/PR、变更和测试结果 | 只读列出完成/偏差/阻塞与验收口径；不得修改文件或外部状态。 |
| `spec_audit` | `prd_consistency_audit` 需要逐字段或测试路径复核时使用的子审计角色 | 当前 PR diff、schema、单元测试、对应 PRD 段落 | 只读寻找 fail-closed、边界条件、来源和测试缺口；向 `prd_consistency_audit` 回报。 |

## 标准启动提示词

所有角色启动时应先声明：本项目仅做研究和人工下单决策支持；不得接入券商、保管凭据或执行订单。审计类角色默认只读。凡涉及费用，必须区分“用户报告下限”“书面费率”和“交割单校准”；凡涉及策略，必须把 30 个交易日标为探索样本。
