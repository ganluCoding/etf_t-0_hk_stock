# ADR-0001：Git 与 DVC 管理本机研究数据

- 状态：Accepted
- 日期：2026-07-25

## 背景

本项目包含代码、PRD、研究结论和分钟级市场数据。原始行情、盘口快照、券商交割单及其缓存可能较大、敏感或受数据授权约束，不适合直接写入 Git 历史。

## 决策

- GitHub 私有仓库中的 Git 管理代码、文档、配置、数据字典、数据集版本指针、质量报告和小型测试夹具。
- DVC 管理原始和派生的大文件数据。初始阶段仅使用本机 DVC 缓存和工作区数据，不配置云端数据 remote。
- 真实原始数据位于 `data/raw/`，中间数据位于 `data/interim/`，处理结果位于 `data/processed/`，第三方输入位于 `data/external/`。
- 数据文件不进入普通 Git。每个可复现实验数据版本都应有 DVC 元数据、来源、获取时间、字段说明及质量报告。
- 未经脱敏的券商交割单、账号信息、密钥和令牌不得进入 Git 或 DVC。

## 后果

- 本机可复现实验及历史数据版本，但本机磁盘故障不能由 GitHub 恢复大文件数据。
- 需要跨设备协作或灾备时，新增私有对象存储/NAS 作为 DVC remote，并以新的 ADR 记录。
- 数据供应商授权条款优先于版本管理便利性。
