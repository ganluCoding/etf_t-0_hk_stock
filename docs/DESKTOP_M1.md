# 目标 ETF 桌面观察应用 M1

- 状态：Implemented
- 任务：Issue #26
- 日期：2026-07-26
- 数据模式：固定测试夹具，不是实时行情

## 用途

M1 是桌面应用的第一条可运行纵向切片。它验证用户只输入目标 ETF 代码后，应用能够完成策略注册检查、连续竞价时段检查、费用覆盖、短时价格展示、过期清除和 No-Go 展示。

它不连接实时数据、券商或账户，不提交订单，也不用于明日交易判断。

## 启动

```bash
uv sync --all-groups
PYTHONPATH=src uv run python -m etf_t0.desktop_app
```

启动后输入 `159570` 并点击“开始观察”。输入其他代码会得到 No-Go，因为 M1 只注册了一个固定策略夹具。

应用直接加载现有资格台账中的 159570 记录和[深交所上市公告](https://www.szse.cn/disclosure/notice/fund/t20240117_605654.html)；固定夹具在启动时验证记录代码与夹具代码一致、资格状态、交易所发行人/官方域名、明确回转原文、复核日和合法 0.001 价位。资格证据 ID 由台账记录内容生成，不是可自由填写的标签。

夹具数据 SHA-256 由目标代码、时间和全部价格字段确定性计算，启动时与冻结策略 lineage 中的记录比对；任一价格被改动而未建立新版本都会失效关闭。

应用启动时将测试时钟锚定在 10:00:15，然后按本机单调时钟继续推进，在 10:00:30 清除显示。过期快照在同一应用会话中不可重放；重新启动应用才能重新演示。这是测试时钟，不代表系统正在接收 2026-07-27 的市场行情。

## 已实现行为

- 日常输入只有六位目标 ETF 代码。
- 主界面只显示目标 ETF，不显示或要求操作任何内部参考标的。
- 159570 夹具通过台账资格证据和费用覆盖后显示纸面观察线，并固定标注“实盘准入未通过”。
- 非六位代码、没有注册策略的代码、非连续竞价时段、未来时间回拨、行情过期或成本不足均失效关闭。
- No-Go 与过期状态清除目标买一/卖一、买入观察线、策略退出线和盈亏平衡参考。
- 资金不足一手时返回 No-Go；100 份小额情景因 4-tick 策略空间不足以覆盖双边最低佣金而 No-Go。
- 费用档案始终显示 `PROVISIONAL`，1.415 仅是已建模最低佣金口径的下界，不是完整可成交盈亏平衡价。
- 界面没有买入、卖出、复制订单、券商链接或自动下单功能。

## M1 限制

- 只支持固定的 159570 演示夹具。
- 不读取本机前向采集数据或公共实时行情。
- 不计算新的策略参数或为任意 ETF 自动选择锚点。
- 不保存设置、人工成交或决策日志。
- 不实现用户报告持仓后的 `EXIT_REQUIRED` 状态。
- 不构成 G2、G3、G4–G8 通过证据。

下一步 M2 将在保持相同公共界面和失效关闭规则的前提下，接入本机目标行情、IOPV、策略注册表和费用档案。
